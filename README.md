# Gaurav Tiwari — Developer Portfolio

Personal developer portfolio website built strictly adhering to the design specifications, featuring a dark-mode theme, infinite skill marquee, live synchronized time, interactive GitHub contribution calendar, and rich project showcase.

## 🛠️ Tech Stack

- **Framework:** React 19 + Vite 6
- **Language:** TypeScript 5
- **Routing:** React Router 7
- **Styling:** Hand-crafted CSS with Design System Tokens
- **Icons:** React Icons
- **Calendar:** React GitHub Calendar
- **Sound:** Web Audio API (tactile haptic click)

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## 📁 Project Structure

```
├── public/                 # Static assets (images, profile, resume PDF, robots.txt, sitemap)
├── src/
│   ├── components/         # Reusable UI components & Blog component suite
│   ├── data/               # Strongly-typed data files (projects, links, uses, images)
│   ├── pages/              # Route pages (Home, Projects, Uses, Blogs, Resume, 404)
│   ├── App.tsx             # Main router and layout
│   └── main.tsx            # React root entry point
├── package.json
└── vite.config.ts
```
